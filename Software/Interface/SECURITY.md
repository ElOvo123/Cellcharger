# Security Policy

## Reporting

Do not open public issues for vulnerabilities or safety-sensitive charger behavior.

Report security or safety concerns privately to the project maintainer with:

- Affected version or commit.
- Steps to reproduce.
- Expected and observed behavior.
- Relevant logs, screenshots, or hardware context.

## Scope

The interface controls charger communications and profile setup workflows. Treat malformed profiles, unsafe command generation, and communication-state bugs as safety-sensitive until reviewed.
